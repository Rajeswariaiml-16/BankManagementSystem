\# Bank Management System



A simple Bank Management System developed using Java, MySQL and JDBC.



\## Features



\- Create Account

\- Deposit Money

\- Withdraw Money

\- Check Balance

\- Transfer Money

\- View Transaction History

\- Close Account



\## Technologies Used



\- Java

\- MySQL

\- JDBC

\- VS Code



\## Database



Database Name: bank\_management



\### Tables



\- account

\- transaction\_history



\## How to Run



1\. Install Java JDK.

2\. Install MySQL Server.

3\. Create the `bank\_management` database.

4\. Create the required tables.

5\. Add MySQL Connector/J `.jar` file to the `lib` folder.

6\. Update MySQL username and password in `DBConnection.java`.

7\. Run `Main.java`.



\## Project Purpose



This project was developed to understand Java, JDBC, MySQL database connectivity and basic banking operations.
